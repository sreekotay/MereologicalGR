## 2. Identity gate

The field-theory identity is not:

```text
virtual photon = tiny photon traveling between charges
```

It is:

```text
virtual photon = photon propagator / exchange kernel between electromagnetic currents
```

Schematic amplitude form:

```text
M ~ j_1μ D^μν(q) j_2ν
```

with the schematic propagator behavior:

```text
D(q) ~ 1/q²
```

The shell condition is the quantitative boundary:

```text
real photon:     q² = 0
virtual photon:  q² ≠ 0
```

For spacelike exchange:

```text
Q² = -q² > 0
```

For timelike exchange:

```text
q² > 0
sqrt(q²) = invariant mass available to final states
```

The framework does not choose `q²`. Standard field theory does. The framework reads `q² = 0` as the on-shell null-carrier boundary and `q² ≠ 0` as the off-shell exchange-kernel register.



This is the first guardrail against substance-smuggling.


The framework reads this as:

```text

```

Microcausality attaches to physical observables, not to internal propagator lines as if they were little objects.

So the role explanation is:

```text

Causal prohibition applies when influence becomes consequential for flow-bearing observable systems.
```

This is not a derivation of the QFT commutator algebra. QFT owns that result. The framework explains why the commutator, not the propagator magnitude, is the correct causality diagnostic.
