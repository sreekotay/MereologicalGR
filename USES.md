claimed and how it dies; this file tracks what the definitions are **for** — which ones act as
locators, which uses have been exercised, and which sit open. The recurring pattern:*

```text
definition → role-location → locator

when a quantity looks one-place, ask which role-package rendered it;
when a claim looks final, ask which tier it occupies and what would constitute it.
```

**parked** (usable in principle; fitting or sprawl risk too high to hunt now). A CLAIMS row
moved by a locator cites its row here; this table records the forcing, CLAIMS records only the
movement.*

pair-correlated noise the count re-atomizes to the event count, and adjacent vs random pairing

unit count. The named candidate: a surface code where only geometrically *aligned* pair-noise
chains across the logical cut. Proposable, not in hand; adjacency stays parked until that
witness (or another) carves it.

## Discipline

A use enters "cashed" only when a note exercises it against a claim that could have resisted —
classification without resistance is vocabulary. A cashed forcing demotes if the movement is
later shown available without the locator — the relabel death, applied to forcings. A use that
stays open across multiple opportunities where it was the right tool gets flagged; a use that,
when exercised, forces nothing, gets demoted to parked with the failure noted. The ledger
inherits the corpus's sterility criterion: locators that stop locating are relabels.
