# DELTA — The Definition Inventory, by Distance from Orthodoxy

*Accounting layer, beside [CLAIMS.md](CLAIMS.md) and [USES.md](USES.md); may reference any
note. CLAIMS tracks what is claimed and how it dies; USES tracks what the definitions are
for; DELTA tracks where each definition stands relative to the closures it touches.*

```text
relabel is not a property of a definition;
it is a property of a (definition, closure) pair.

column values:
  relabel     the closure already says this
  gap         the closure is silent here
  constraint  the closure's practice or narrative must change
  bet         the closure's expected future is wagered against
```

The GR column is all relabel-or-gap **by design**: GR is held fixed, so there is nothing to
fit a carve to — which is exactly what makes the same definition's work at contact
witness-eligible instead of axiom-to-fit. The GR column is the lineage bank; the export
column is where delta is priced. This file sorts by the export column.

## The method layer — orthogonal column

Not definitions of physics; definitions of how claims are graded. Their delta is not against
physics but against theory-defense practice:

```text
calibration ≠ fitting          the anti-numerology firewall
lineage, not chronology        retrodiction admissible only when the carve predates contact
forced / chosen / imported / parked   every claim states its provenance
null guards (ε = 0 class)      semantic content must not add physics

```

A framework that pre-answers criticism by deflecting is unfalsifiable; one that routes
criticism to static kill tests is attempting maximal falsifiability. That routing is these
five definitions.

## Discipline

Rows move on the USES criterion: a Band 3b definition enters Band 2 or 1 only when a note
exercises its export face against a claim that could have resisted. Demotion runs the other
way: an export face that collapses to relabel at contact is the failure mode, and the row
records it rather than being deleted. A definition whose export column stays empty across
multiple contacts where it was the right tool gets flagged (adjacency is the standing
example). Every row must cite the note that prices it; a DELTA row with no home is
vocabulary.
