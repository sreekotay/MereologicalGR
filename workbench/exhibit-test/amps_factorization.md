# Running the exhibit test on state-level AMPS

The import critique (QM's observer in a GR question) reaches the operational branch and leaves the
state-level argument untouched. That argument mentions no observer:

```text
unitarity          b is maximally entangled with R  (the early radiation)
equivalence princ. b is maximally entangled with b~ (its interior partner)
monogamy           a system cannot be maximally entangled with two others
=> contradiction
```

A0 §11's test, applied to the question *is b entangled with both?*

## 1. Name the composite the question asks about

`maximally entangled with` — read in the argument as a **two-place** relation on subsystems.

## 2. Name its co-required roles

It is not two-place. Entanglement is a property of a **state together with a factorization**:
`S(ρ_A)` is defined only once `H = H_A ⊗ H_Ā` is fixed. So the relation is

```text
entangled(state, factorization, A, Ā)
```

Monogamy is a theorem *within one factorization*. It constrains three factors of a single
tensor decomposition.

## 3. Exhibit the role absent where the question demands a value

The two legs are stated in **different factorizations**:

```text
unitarity leg       factorization  b | R      | rest
no-drama leg        factorization  b | b~     | rest
```

The argument demands a single value for "what b is entangled with" while supplying two
factorizations and naming neither. For monogamy to bite, `R` and `b~` must be **independent
factors of one decomposition**. That requirement is never exhibited — it is carried implicitly by
writing the relation as two-place.

**Verdict: malformed.** The suppressed argument is the factorization.

---

## Why this case is worth running: the answer is already known

The field's own resolution says the factorization was the error. After the Page time the island —
the black hole interior — lies inside the **entanglement wedge of the radiation**, so interior
degrees of freedom are encoded in `R`. Then `b~ ⊂ R`, the two legs are not independent factors,
and monogamy never applied. Same for the ER=EPR reading: interior and radiation are not separate
systems described separately, they are one system described twice.

So the test, run blind on the composite, names the factorization — and the resolution the field
actually reached is that the factorization was wrong.

## What this is and is not

```text
is:      a retrodictive validation of the exhibit test on a case whose answer
         is settled independently. The instrument picked the right suppressed
         argument without being told the answer.
is not:  new physics. Islands and ER=EPR own the resolution.
is not:  evidence the grammar would have got there first -- it would have
         named the missing argument, not supplied the island formula.
```

The value is calibration. Every other application of this test in the corpus has been to an open
dispute, where "the question is malformed" cannot be checked. This is the first closed case, and
the test passes it.

## The honest limit

Naming the factorization as suppressed is cheap once you know entanglement needs one. The test
does not say *which* factorization is right, and that is where all the physics is — the island
formula is a computation, not a role assignment. So the instrument's reach is: it locates the
argument that was suppressed. It does not supply its value.

Which is a fair statement of what a mereological audit can do, and worth having demonstrated on a
case with a known answer rather than asserted.
