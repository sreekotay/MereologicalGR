# Diamond removal — verdict reproduction

Complementarity's diamond posit answers one question: **is there a single observer who can
hold both descriptions?** Bousso's form carries a substantive extra claim — *there must be a
theory for every causal diamond, but not necessarily for spacetime regions too large to be
contained in any causal diamond.*

The write-chain criterion asks instead: **is there a single write-chain that constitutes both
facts?** Constitution is ordered influence taken up in flow at a pinned threshold (PB-4), so a
"chain" is a physical register path, not a region and not an agent.

## Case 1 — Xeroxing / no-cloning

| | |
|---|---|
| **diamond** | Bob's reading and Alice's reading lie in different causal diamonds → no contradiction |
| **write-chain** | Bob's chain: radiation → his detector → threshold. Alice's: interior mode → her detector → threshold. Two chains, two registers, on different worldlines. Joining them needs a signal from Alice's register to Bob's, which the horizon blocks. No single chain constitutes both. |
| **verdict** | **same** |
| **used** | GR causal structure only — the horizon blocks the signal. No posit. |

## Case 2 — AMPS decode-then-jump

| | |
|---|---|
| **diamond** | the early radiation lies in the infalling observer's diamond → complementarity **fails** |
| **write-chain** | Alice decodes → writes to register R → carries R across → measures interior mode → writes R′ → compares. One worldline, one chain, all writes local. One chain constitutes both. |
| **verdict** | **same — the contradiction is live** |

Note what this costs: the write-view **does not rescue complementarity**. It reproduces the
failure. Harlow–Hayden is still required for the resolution on this reading too.

## Case 3 — the Page transition

| | |
|---|---|
| **diamond** | radiation entropy rising then falling is consistent because descriptions are per-observer |
| **write-chain** | radiation entropy is a state functional. Nothing was written at any point, so no constituted fact exists on either side. Consistent because there is no fact to conflict. |
| **verdict** | **same verdict, different reason** |

## Score

Three verdicts reproduced. Dropped:

```text
the per-diamond theory posit
the "regions too large for any diamond" clause
any criterion for what an observer can "verify"
```

Replaced by: GR's causal structure, plus the requirement that a chain be one chain. Both
already owned.

---

## Where the two criteria come apart

**One observer, two registers, never rejoined.** Alice releases a register outside the horizon,
crosses, and measures the interior mode into a second register. Both events lie in Alice's
causal diamond, so the diamond criterion licenses combining the results. But no write-chain
holds both — the registers never meet.

```text
diamond criterion:     permits combination  (one observer)
write-chain criterion: forbids it           (two chains)
```

**The reverse divergence does not exist.** A chain requires signals; signals require causal
connection; causal connection implies a diamond containing the chain. So the write-chain
criterion is never the weaker of the two.

**Therefore the write-chain criterion is strictly stronger**: same verdicts on every extant
case, no posit, and it forbids one combination the diamond permits.

## Consequence for AMPS

The argument's requirement is sharper than "a single observer." It is **a single register**.
AMPS satisfies it — Alice reads both herself — so the argument stands. But a variant in which
the decoded bit and the interior measurement land in registers that never rejoin does not form
a contradiction, even with one observer and one diamond.

## Prior art — the replacement is published

The diamond→record substitution is not ours.

- **The Informational Observer in Relational Quantum Mechanics** (arXiv:2603.02978) grounds
  observerhood in *the coherence of records across time*: an observer exists only when their
  records embed into a **single diachronic history**. Framed explicitly as a shift from spacetime
  geometry to information storage.
- **Zurek, Quantum Reversibility Is Relative** (arXiv:1808.08598; Phil. Trans. R. Soc. 376,
  20170315) supplies the irreversibility half: *retention of the information suffices — there is
  no need for consciousness; the record of the outcome is enough.*

So the verdict reproduction above re-derives a published replacement. Seventh prior-art hit of
the campaign.

**What may not be covered.** The *one register, not one observer* sharpening — whether "single
diachronic history" already forbids the drop-a-register-then-cross variant. Unresolved from
summaries; needs the paper.

**What is distinct, and is the same residue every other route has left.** Zurek's criterion is
**retention** — extrinsic, relative to whether the observer keeps the record. The write-chain
criterion is **intrinsic**: constitution consumed proper time, so the write is irreversible
whether or not anything is retained. Same intrinsic/extrinsic axis that survived Mukherjee &
Hance's Pseudo Events, reached here by an unrelated route.
