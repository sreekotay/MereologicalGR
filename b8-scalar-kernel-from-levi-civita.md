## 1. Why Levi-Civita matters

A0 treats the connection as GR's comparison / transport structure. Once the metric is held fixed, the Levi-Civita connection is the unique torsion-free, metric-compatible way to compare tangent data across the manifold.

For B8, the relevant point is not only vector transport. It is that Levi-Civita also defines the scalar wave operator:

```text
□_g φ = ∇_μ ∇^μ φ
```

For a scalar:

```text
∇_μ φ = ∂_μ φ
```

but the second derivative and divergence require the metric / Levi-Civita structure:

```text
□_g φ = |g|^{-1/2} ∂_μ( |g|^{1/2} g^{μν} ∂_ν φ )
```

So pure GR gives more than a distance measure. It gives the natural scalar propagation operator on the geometry.

MGR reading:

```text
metric:
  ordering + adjacency + clock/separation magnitudes + signature

Levi-Civita:
  comparison / transport that preserves that metric structure

scalar □_g:
  minimal scalar relatedness propagation generated by that transport
```

This is the pure-GR foothold the B7 scalar kernel needs.

## 3. Run 2 — deriving the scalar interval kernel skeleton

### 3.1 Flat local scalar operator

In flat 4D spacetime, the massless scalar operator is:

```text
□ = -c^{-2} ∂²_t + ∇²
```

or, with `x⁰ = ct`, schematically:

```text
□ = η^{μν} ∂_μ ∂_ν
```

The Green-object must solve:

```text
□ R(x,x′) ∝ δ⁴(x-x′)
```

Because the operator is Lorentz invariant and the scalar has no indices, away from coincidence the solution can depend only on invariant separation:

```text
R(x,x′) = F(σ)
```

where:

```text
σ ≈ (x-x′)²
```

This earns the dependence on interval/world-function data.

### 3.2 Dimensional / singularity pressure

In four spacetime dimensions, a massless scalar Green-object with no additional scale must have dimension:

```text
[R] ∼ length^{-2}
```

The only available invariant with that dimension is:

```text
R ∝ 1/σ
```

where `σ` is quadratic in separation.

So the leading scalar kernel skeleton is forced:

```text
R_skel(x,x′) ∝ 1 / σ(x,x′)
```

This is not yet a Wightman function. It is the scalar interval singularity skeleton.

### 3.3 Null-cone singularity

Because:

```text
σ(x,x′) = 0
```

on null separation, the skeleton is singular on the light cone.

MGR reading:

```text
ordering boundary:
  null cone

scalar relatedness singularity:
  concentrated at the ordering boundary
```

This is exactly what the photon seed would lead one to expect: massless scalar relatedness is organized around the null boundary, where flow is stripped but ordering remains.

### 3.4 Hadamard local form

In curved spacetime, the local scalar singularity is controlled by the same geometry. The generic local form has the schematic Hadamard structure:

```text
G(x,x′) ∼ U(x,x′)/σ + V(x,x′) log σ + W(x,x′)
```

with the leading singularity governed by the world-function `σ` and transport/focusing data such as the Van Vleck determinant.

B8 does not derive the full Hadamard expansion. But it identifies what GR owns:

```text
GR-owned:
  σ(x,x′), the geodesic interval/world-function;
  transport/focusing factors along geodesics;
  the local null-cone singular locus;
  the leading 1/σ scalar skeleton in 4D.

not GR-owned here:
  global state;
  boundary conditions;
  vacuum selection;
  W term / state-dependent smooth part;
  full quantum meaning of the two-point object.
```
