# A3 — Record Is Not Constitution

*Working draft, June 2026.*

Status: application document / quantum-Darwinism boundary.  
Primary target: A0 information grammar, A1 photon-run record/uptake split, and PB-4.  
Grade: mathematical reduction + diagnostic-program bet. Not a new quantum-measurement theory.

A3's claim is simple:

```text
record is state-structure;
constitution is uptake-operation.
```

Quantum Darwinism diagnostics measure record. They are functionals of the joint system-fragment state. Constitution, in MGR, is a flow-bearing uptake/write: an operation applied to a fragment, not a number already contained in the state.

Therefore:

```text
QD diagnostics can measure record-readiness.
They cannot locate constitution itself.
```

QD remains the record theory. A3 marks the boundary: record structure is not the same job as constitution.

---

## 1. The committed distinction

A0/A1 define:

```text
information = ordering + influence + flow
```

Information is constituted when ordered influence is taken up in flow at application consequence scale.

A redundant environmental record is different:

```text
record:
  ordered influence-structure available in the environment

constitution:
  consequential flow-bearing uptake / write
```

So:

```text
record ≠ information constitution
```

The environment can contain a proliferated record before any particular uptake completes constitution.

## 2. The mathematical reduction

Quantum Darwinism diagnostics are functionals of the system-fragment state `ρ_SF`.

Standard examples:

```text
partial information curve:
  I(S:F)[ρ_SF]

redundancy:
  R_δ = 1/f_δ

spectrum broadcast structure:
  an exact structural condition on ρ_SF
```

All are read from the state.

Constitution, by contrast, is an operation on the fragment:

```text
constitution:
  a flow-bearing uptake / measurement / CPTP map / POVM applied to F
```

So the sharp statement is:

```text
Record diagnostics ∈ functionals of ρ_SF.
Constitution ∉ functionals of ρ_SF.
Constitution is an operation on ρ_SF, not a scalar read off ρ_SF.
```

Equivalent form:

```text
Record = available correlation / broadcastable structure.
Constitution = uptake crossing application consequence threshold.
```

You cannot read an operation off its own operand.

## 3. What this explains in QD

The record/constitution split explains why QD's recurring diagnostic problems do not disappear merely by improving state diagnostics.

### 3.1 Objectivity thresholds remain conventional in application

If constitution is not a state-functional, no value of `I(S:F)` can be the point where record becomes constituted information.

A `δ` threshold can be useful, but it is a convention:

```text
record threshold:
  useful application criterion

constitution:
  uptake/write operation
```

Exact state criteria can avoid a `δ` only in idealized cases. Real states reintroduce distance, approximation, decoding, timescale, or application thresholds.

### 3.2 Mutual information conflates record with residual entanglement

Quantum mutual information sums correlations in `ρ_SF`.

```text
classical broadcastable record:
  correlation in the state

residual entanglement / discord:
  also correlation in the state
```

Separating them requires a measurement-relative split: accessible information, classical correlation, discord, pointer basis, or an equivalent uptake specification.

So QMI can overstate objectivity because it counts more than classical record.

### 3.3 Redundancy can grow after decoherence saturates

Decoherence saturation and redundancy growth are both state processes, but they are not constitution.

```text
decoherence saturation:
  ρ_S becomes pointer-diagonal / mixed

redundancy growth:
  the same record is copied into more fragments

constitution:
  later uptake/write crossing a consequence threshold
```

Thus redundancy can grow while decoherence has already saturated without implying a new constitution event in the state.

Single sentence:

```text
QD is looking for constitution in the record, but constitution is at uptake.
```

## 5. SBS split verdict

Spectrum broadcast structure was the named test.

Verdict:

```text
against the strong claim:
  exact SBS is basis-intrinsic;
  when exact SBS holds, the pointer basis is readable from ρ_SF.
```

So the unconditional claim:

```text
no state-functional objectivity criterion can exist
```

is false.

But the refined claim survives:

```text
exact SBS is idealized;
real states require distance-to-SBS or approximation thresholds;
SBS is sufficient, not necessary;
its authority comes from a measurement-anchored definition of objectivity;
the dynamics that create SBS are measurement-interaction shaped.
```

Net:

```text
state structure can encode record-readiness;
constitution itself still does not appear as a state feature.
```

This is the important correction: A3 does not claim QD lacks state criteria. It claims state criteria locate record/objectivity structure, not completed constitution.

## 8. Redshift contact

Cosmological redshift is the everyday instance of the same transit/constitution split.

The pseudo-problem:

```text
where does the redshifted photon's energy go?
```

presupposes that photon energy is an in-flight constituted property.

GR's careful answer is already two-place:

```text
E = -p · u
```

Energy is the flow-projection of the photon's four-momentum onto a receiver/comoving worldline. Different epoch, different worldline, different rendered energy.

MGR reading:

```text
in flight:
  ordering + influence with flow → 0;
  no flow-bearing register for energy to drain from

at uptake:
  receiver worldline renders E = -p·u
```

So the pedagogical debate between Doppler-style and expanding-space narratives persists because it seeks an in-flight mechanism in an empty register. Both compute the same frame/worldline comparison; the mechanism story is overlaid.

Grade:

```text
clarifier;
not a new number;
useful because it exposes the record/constitution split in ordinary GR language.
```
