```text

real photon = ordering + influence, with flow absent by nullness
```

A virtual photon shares the word but not the absence-type.

```text

```

The shared label `photon` carries no role-weight by itself.

This contact is not another photon case. It is the negative-control for photon-language:

```text

```

That distinction is lineage-witness grade. It is fixed before QFT contact.

## 3. Identity and shell gate

The field-theory identity is not:

```text
virtual photon = tiny photon traveling between charges
```

It is:

```text
virtual photon = photon propagator / exchange kernel between electromagnetic currents
```

Schematic amplitude form:

```text
M ~ j_1μ D^μν(q) j_2ν
```

with schematic photon-propagator behavior:

```text
D(q) ~ 1/q²
```

The shell condition is the quantitative boundary:

```text
real photon:     q² = 0
virtual photon:  q² ≠ 0
```

For spacelike exchange:

```text
Q² = -q² > 0
```

For timelike exchange:

```text
q² > 0
sqrt(q²) = invariant mass available to final states
```

MGR does not choose `q²`; standard field theory supplies it. MGR reads `q² = 0` as the on-shell null-carrier boundary and `q² ≠ 0` as the off-shell exchange-kernel register.

Timelike exchange is photon-only at low scales; once electroweak scales matter it mixes with the Z (`γ*/Z`). So `q² ≠ 0` names an off-shell exchange register, not a pure-photon object.

The internal photon line is representation-dependent: gauge choice and perturbative organization affect how the calculation is written. Physical cross-sections and S-matrix elements are the gauge-invariant outputs.

## 5. Microcausality seam

This is the sharpest contact. The carve is fixed in §1–§2; microcausality is where it lands a guardrail, not its source. The reading here is convergent with standard QFT and carries thin weight on its own.

Standard QFT distinguishes several objects that informal language often compresses:

```text
Feynman propagator:
  time-ordered calculation kernel
  may have off-light-cone / spacelike support

commutator / Pauli-Jordan function:
  causality diagnostic
  vanishes at spacelike separation for local observables

Wightman / correlation functions:
  correlation structure
  not by themselves signal or control
```

MGR reads this as:

```text
propagator support ≠ causal signal
kernel relation ≠ constituted influence event
correlation amplitude ≠ information transfer
```

Microcausality attaches to physical observables, not to internal propagator lines as if they were little objects.

```text
A virtual photon may appear in an off-shell kernel because it is not a carrier-event.
Causal prohibition applies when influence becomes consequential for flow-bearing observable systems.
```

This is not a derivation of the QFT commutator algebra. QFT supplies that result. MGR locates why the commutator, not the propagator magnitude, is the correct causality diagnostic.

The Sokhotski split lives in virtuality (`q²`); spacelike support lives in position space. The split does not license reading extended kernel support as signal. Causality stays on the commutator side.

```text
Do not test causal order on internal kernel support.
Test causal order on physical observable commutators / signal possibility.
```

That is exactly where standard QFT places the test.

## 6. Magnitude import

MGR does not compute QED cross-sections. QED supplies them.

MGR assigns the role boundary. External physics prices it.

The following are schematic currencies, not universal cross-section claims. Real calculations require the full gauge-invariant amplitude, including form factors, PDFs where relevant, phase space, spin structure, loop and radiative corrections, experimental cuts, and the chosen observable.

Virtuality is a boundary currency, not a role-strength scalar. `q²` / `Q²` prices the off-shell exchange inside QED. It does not measure how much influence MGR assigns, and it should not be promoted into a hidden universal magnitude of influence.

```text
virtuality:
  q² or Q²

  roughly ~ 1/q² for simple photon exchange

```

Examples:

```text

Q = 1 MeV  →  length ~ 200 fm
Q = 1 keV  →  length ~ 0.2 nm
```

For timelike virtual photons, the threshold currency is invariant mass:

```text
sqrt(q²) >= 2m_e   → e+e- possible
sqrt(q²) >= 2m_μ   → μ+μ- possible
```

Role reading:

```text

```

The virtual photon itself does not become a flow-bearing object. The final particles do.
