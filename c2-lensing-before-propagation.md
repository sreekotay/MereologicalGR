# C2 — Path Before Propagation

*Exploratory — not canon. Companion kill-lane for [C1](c1-gw170817-propagation.md).*
Grade: diagnostic / role-guard. Not a claim that any event is lensed, not a propagation model.

A gravitational-wave residual is not yet a propagation residual. A lens changes the *route* before a
cone changes the *law*: it can move arrival time, phase, amplitude, and inferred source parameters
while the local propagation rule is untouched. So a cone-delta (C1) has a prior bill — the cone is the
**last** carrier audited, not the first.

    Before propagation is allowed to move,
    the non-cone carriers must fail to carry the residual.

This is the A0 missing/extra discipline aimed at propagation: C1 alone is coefficient-shopping; C2 is
the anti-self-deception lane that makes each non-cone role pay its own account first.

## The residual arrives bundled

    observed anomaly = source engine + path/lensing + waveform model
                     + amplitude-distance inference + detector/population prior + propagation cone

Forbidden collapses: phase anomaly = propagation; amplitude anomaly = propagation; arrival offset =
cone delta; lensing residual = modified propagation; source outlier = new dynamics.

## Bill order — calibrated to C1, not to the generic case

The carriers are not equally able to mimic **C1's specific signature** (achromatic, constant,
distance-scaling, sign-stable). Order them by that ability:

1. **Source-emission timing** — the primary degeneracy (C1's intercept-vs-kernel; the whole reason one
   event can't separate source from propagation).
2. **Population / selection scatter** — a carrier-class trend read as a distance trend.
3. **Waveform systematics** — acute for heavy, short-duration signals.
4. **Amplitude-distance / lensing magnification** — enters C1 *narrowly*: not as a mimic of the timing
   residual but as **noise in the d_L axis** that Δt is scaled against.

Lensing-as-path-mimic sits low for C1, because of one fact:

**Microlensing is chromatic; C1 is achromatic.** Wave-optics amplification F(f) oscillates with
frequency (scale ∝ GM·f/c³), so lensing is the natural mimic of a *dispersive* anomaly — a massive
graviton, energy-dependent speed — and a structurally poor mimic of a constant cone. The strong-lensing
macro-delay *is* achromatic, but it tracks lensing optical depth and discrete images, not comoving
distance. So C1's licensing signature is the joint condition no lensing carrier reproduces:

    achromatic  AND  scales with comoving distance  AND  sign-stable,
    with the residual NOT tracking optical depth, source class, or waveform family.

Chromatic microlensing fails the first; achromatic strong-lensing fails the second. C1's own predicted
structure discharges the lensing carrier — lensing is not C1's main threat, source-timing and
population are.

## Population scaling is a kernel shape, not a slope

C1's propagation term is an accumulation kernel of unknown shape (see C1, *Source vs propagation*), so
the test is which shape the residual follows, in comoving distance:

- constant cone → linear in comoving distance (C1);
- ∝ ∫Φ dl → structure-lumpy, correlates with line-of-sight potential (H_p2);
- tracks **source class / host / lensing probability / waveform duration / detector network** → a
  non-cone carrier, and C1 demotes.

## GW231123 — a gate, not a witness

GW231123 is a useful contact because it sits at the seam: an apparent **massive-graviton** posterior in
unlensed analyses that unmodeled point-mass lensing can absorb. Two things to keep straight:

- The mimicked signal there is **dispersive** (massive graviton). C1 is **not**. So GW231123
  illustrates the *generic* "path imitates propagation" danger for a *neighbor* of C1 — and the
  chromatic/achromatic split is exactly why it's an analogy, not a direct C1 contact. That distinction
  is protective: lensing mimics the dispersive neighbor, not the achromatic cone.
- The lensing interpretations are imported and unverified. C2's validity must not depend on GW231123
  turning out lensed. It is a gate that exposes the failure mode, not evidence.

## The lensed image-delay test belongs to H_p2, not C1

For a *constant* cone, two lensed images close: Δt_GW,12 − Δt_EM,12 ≈ ε·Δt_lens ~ nanoseconds
(ε·10⁶ s), whether or not C1 is true — both messengers scale the same short lens delay by (1±ε). So
image-delay closure does **not** demote constant-ε C1; it demotes the potential-coupled cone (H_p2),
where the delay lives in the lens's Φ. The clean multimessenger lever for C1 is the *cosmological*
baseline (the whole path), not the lens delay. Assign Δt_GW,12 vs Δt_EM,12 to the H_p2 audit.

## Collision room — C2 is falsifiable

C1 survives C2 if, after source timing, population, waveform, amplitude-distance, calibration, and
lensing are each priced, a residual remains that is achromatic, sign-stable, and scales with comoving
distance rather than any carrier class. C2 demotes if every non-cone carrier is exhausted and a clean
cone residual is what's left. It is a kill lane, not a permanent escape hatch.

## Owned vs imported

Owned: the role split (cone / path / Fermat / phase / amplitude / source / inference); the rule that
propagation is the last carrier; the demotion path (C1 falls when the residual routes through a
non-cone carrier). Imported and not owned: event data, lensing and waveform models, massive-graviton
parameterizations, Bayesian inference, detector calibration, all numerical bounds, and the GW231123
interpretations.
