*Working draft, June 2026.*

Status: foundation-adjacent hinge note.  
Primary target: A0 rendering/uptake seam, A2 gravity transport map, B6 temperature discipline, and B7 scalar-response computation.  
Grade: operational hinge / witness-placement note. Not a new dynamics, not a new field equation.

A0 gives the photon seed:

```text
photon:
  ordering + influence remain;
  flow is stripped

therefore:
  cause cannot require flow
```

A0a gives the second hinge:

```text
acceleration:
  flow remains;
  the frame-basis changes through flow

therefore:
  rendering cannot be treated as a passive label
```

Together:

```text
photon:
  influence can exist without flow
```

---

## 1. The hinge claim

The claim is not merely:

```text
acceleration changes detector response
```

The stronger claim is:

```text
acceleration is the cleanest local witness that frame is not a passive label.
```

More fully:

```text
Acceleration is the cleanest local witness that a flow-bearing system
transports its rendering basis, and that this transport can change which
influence becomes response-capable before any information is written.
```

This is why acceleration matters foundationally. It is not only a B7/Unruh calculation. It is the local operational face of frame-transport.

---

## 2. Role map

A0's static grammar remains:

```text
cause = ordering + influence

time = ordering + flow

frame = ordering + flow + adjacency

information = ordering + influence + flow

gravity = ordering + influence + energy-momentum
```

A0a adds the operational grammar:

```text
influence
→ rendering through frame
→ frame-transport through flow
→ uptake
→ information
```

Equivalently:

```text
information is not merely influence plus a clock;
information is ordered influence after frame-conditioned uptake in flow.
```

The original composition remains valid. The operational expansion prevents it from being read as a static ingredient list.

---

## 3. Influence implication

Influence is floored as:

```text
influence = consequence-capable phase-bearing relatedness
```

Acceleration sharpens the meaning of `consequence-capable`.

```text
If changing frame-transport changes the response,
then the sampled relatedness was capable of consequence under at least one flow-bearing rendering.
```

This does not mean acceleration creates influence.

It means:

```text
acceleration can reveal the response-capacity of influence
by changing how relatedness is sampled and rendered through flow.
```

So influence is not merely present relatedness. Influence is relatedness that can survive routing into a response difference.

---

## 4. Information implication

The photon seed blocks:

```text
influence in transit = information
```

Acceleration blocks the opposite simplification:

```text
information = influence + any clock
```

The missing operation is frame-conditioned rendering and uptake.

```text
same relatedness
+ different frame-transport
→ different response rendering
→ possible different uptake/write
```

So the better operational statement is:

```text
information = ordered influence taken up through a transported frame
at application consequence scale
```

or, keeping A0's existing formula visible:

```text
information = ordering + influence + flow
with the operation:
  influence → rendering → frame-transport → uptake
```

Rendering is not constitution. Frame-transport is not constitution. Uptake/write is where information becomes constituted.

## 5. Gravity implication

A2's gravity reading becomes more central under A0a.

```text
gravity is not frame-transport itself;
gravity is the energy-momentum-conditioned structure of frame-transport.
```

The operational split is:

```text
proper acceleration:
  local non-geodesic / forced frame-transport along flow

geodesic deviation:
  relative frame-transport of nearby flow-lines

curvature / holonomy:
  loop frame-transport / rotational closure failure

torsion, if live:
  translational closure failure of transport
```

Thus gravity belongs on the transport side:

```text
energy-momentum
→ connection / curvature behavior
→ frame-transport
→ changed rendering / response conditions
→ possible uptake/write
```

Information belongs on the uptake side:

```text
ordered influence
→ rendered through frame
→ transported through flow
→ taken up / written
```

The bridge between them is not that gravity is information. The bridge is that both share ordering + influence, while gravity acts through transport structure and information completes through uptake.

## 6. Acceleration and temperature

B7 shows the clean computation:

```text
uniform acceleration
→ hyperbolic worldline
→ scalar interval skeleton pullback
→ sinh^-2[aΔτ/(2c)]
→ β_τ = 2πc/a
```

B6 gives the role reading:

```text
temperature = flow-indexed response scale of accessible relatedness / mixedness
```

A0a locates why this matters:

```text
acceleration changes frame-transport;
frame-transport changes rendering;
rendering can change response scale;
response scale can become informational only after uptake/write.
```

So the Unruh lesson is not:

```text
observer imagines particles
```

and not:

```text
acceleration creates information
```

It is:

```text
same relatedness;
different frame-transport;
different response rendering;
possible write if detector threshold is crossed.
```

## 7. Why this is not overclaim

A0a does not claim:

```text
acceleration is all frame-transport;
all frame-transport is proper acceleration;
gravity is frame-transport simpliciter;
Unruh derives the vacuum;
thermal response is information constitution;
observer-dependence is eliminated from all descriptions.
```

It claims:

```text
proper acceleration is one measurable non-geodesic face of frame-transport;
frame-transport is operationally real because it changes rendering conditions;
changed rendering is not yet uptake;
uptake/write is still required for constituted information;
gravity conditions transport structure through the imported GR machinery.
```

That is the correct weight.
